🚀 Instalación y uso

📥 Descargar el proyecto

Descargá los dos archivos del repositorio y colocalos en una carpeta.

⚙️ Paso 1 — Instalar dependencias

Abrí una terminal en la carpeta del proyecto y ejecutá:

python instalar.py

▶️ Paso 2 — Ejecutar el bot

Una vez instaladas las dependencias, iniciá el bot con:

python bot_trading.py

📌 Nota

Asegurate de tener Python instalado correctamente antes de ejecutar los comandos.
